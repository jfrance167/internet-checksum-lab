# Consequential choices

- Build the owned MIT arithmetic pattern plus original stdlib wrapper, rather than
  installing/forking broad packet packages. dpktBSD3/ScapyGPL2-only sources were
  inspected at pinned revisions with license/metadata/CI/test evidence; none adopted
  or executed. Retrieval fallback and uncertainties remain in RESEARCH.md.
- Freeze exact schema,21full expected reports,5envelopes/status/error priority and
  SHA256 receipts before implementation. Common admission precedes all evaluation.
- Distinguish arithmetic residual from exact checksum equality and expose both zero
  representations unchanged. No automatic wire-field semantics or authenticity claim.
- Eq3 supported only for one aligned replacement with an unchanged nonzero OTHER
  word. Conservative lab restriction, not an RFC requirement. Historic Eq2 output is
  diagnostic only, with independent full recomputation beside Eq3.
- Use strict JSON-only exact bytes API and closed scalar output shape. Logical caps
  bound admission/report size; no hard process-resource containment claim.
- CLI counts must be exact built-in integers equal to text length; no coercion.
  Detach failed streams on OSError/ValueError. Configure native CLI LF translation
  explicitly after a real Windows diagnostic mismatch; retain zero/error byte contract.
- No CRC32C addition: it requires a separate bit mapping/init/polynomial/serialization
  profile and independent controls. No real traffic/devices/repos/install/publication.
- Local worker accepted only a four-label extraction. No arithmetic/code oracle from
  model output. Codex performed source/math/security judgments and ECC self-review.
